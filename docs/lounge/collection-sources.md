## Selection notes

- Parmigiano: the 60-month whole-wheel example and image are from the Gourm.it selection; weight and dairy must be confirmed with the supplier.
- Lambrusco: Chiarli Vecchia Modena is the producer example. Bottle photograph from the Coopshop retail listing. The original Chiarli product page is linked for product information.
- OpenExo: GitHub README and the Northern Arizona University project pages were consulted. Research parts/build enquiries are separate from retail purchases.
- OpenCat: GitHub README identifies the linked repository as the legacy NyBoard platform; Bittle X uses the current ESP32 branch.
- The Giorgio Brato pages expose both purchasing controls and sold-out text. Cards therefore say to check with the maker, rather than claiming stock.
- Bialetti reference pricing is the US store’s entry price and may vary by size or promotion. Lussino is an enquiry because regional voltage and distribution differ.
- Original Energica concept objects remain clearly labelled and keep their existing IDs, so saved selections are preserved.
